Configure cada unidade aqui. GPIOs são sugeridos e podem ser alterados. A calibração é individual: YF-B7 = 660 pulsos/L; YF-S201 = 450 pulsos/L como referência editável.

Reduzir a quantidade ou desmarcar Família YF desativa as unidades correspondentes na configuração. Seus IDs e parâmetros são guardados para reativação. Para liberar capacidade para outro sensor, remova explicitamente a configuração de uma unidade desativada. Guarde, grave e reinicie o ESP32 para aplicar.

Relógio e operação sem internet

Preserva a hora UTC ao desligar e ligar sem rede. O NTP tem prioridade e ajusta o RTC automaticamente. Sem módulo, deixe desmarcado.

SENSORES CUSTOMIZADOS — 8 instâncias configuráveis

GENERIC_SENSOR V1 + NTC Beta — formulário por interface: configure sensores que não existem no catálogo usando motores já incorporados ao firmware. Selecione a interface para exibir somente os parâmetros correspondentes. O firmware não identifica o sensor pelo nome/modelo.

Os sensores das famílias YF e MQ são configurados no catálogo. Desativar uma unidade preserva os parâmetros para reativação.

Correção metrológica — y = a × x + b

2 correções metrológicas disponíveis. Escolha o sensor/canal habilitado e depois a grandeza. Vale para sensores nativos e customizados. Linhas OFF e vazias são ignoradas.
Separador decimal: use ponto (.) nos coeficientes, por exemplo a = 1.0234 e b = -12.5. Não use vírgula.

Preencha e guarde a configuração antes da instalação.
ETAPA 2 — INSTALAÇÃO

Instale o SENS

O Wi‑Fi automático do ESP Web Tools está desativado nesta versão. Terminada a instalação, use a Etapa 3: ela grava automaticamente o Nome + Serial já salvos e, na mesma conexão USB, segue para a rede.

ATUALIZAR — PRESERVAR DADOS: mantém NVS/identidade do equipamento (Epoch, próximo Seq e configurações). Se o gravador apresentar uma opção de apagar dados, escolha NÃO APAGAR / manter dados.
ETAPA 3 — GRAVAR CONFIGURAÇÃO SENS

Envie a configuração salva ao ESP32

Depois de instalar, selecione a porta do ESP32 para gravar a configuração completa. O equipamento confere os dados relidos da memória antes de confirmar a conclusão.

Aguardando instalação e conexão com o ESP32.
ETAPA 4 — REDE • ÚLTIMA ETAPA

Configure o Wi‑Fi

A configuração SENS termina completamente na Etapa 3. Para configurar a rede, clique em PREPARAR WI‑FI, selecione novamente a porta do ESP32 e então escolha uma rede detectada ou digite o SSID manualmente.

Conclua a Etapa 3 antes de configurar o Wi‑Fi.
